# Real Time IoT based organ transport monitoring system
# Overview:
This project implements a real-time monitoring and decision-support system for organ transportation using simulated IoT sensor data and machine learning techniques. The system models temperature, location, and transport conditions to detect anomalies and assess transport risk in near real-time.

The project is developed as a proof-of-concept digital twin to allow controlled experimentation without reliance on physical IoT hardware or sensitive clinical data.

# Core Features
  Simulated IoT sensor data for organ transport conditions
  Real-time data ingestion and processing backend
  Unsupervised anomaly detection for transport deviations
  Machine learning-based risk classification
  Visual dashboard for situational awareness and alerts

# Technologies
  Python
  FastAPI (backend)
  MQTT / WebSockets (real-time communication)
  Scikit-learn (machine learning)
  Streamlit / Web frontend (dashboard)
